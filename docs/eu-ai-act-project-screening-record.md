## 1. System and intended purpose

- **What does the system do?** Accepts synthetic CRM contacts, deals, and optional association CSV exports. Deterministic Python rules produce structured findings and report artifacts. A chat integration passes report content to a configured hosted model for natural-language explanation.
- **Provider’s stated intended purpose:** No separate supplier/provider statement for the integrated S02 system is established. The project-authored portfolio purpose is to demonstrate selected CRM data-quality checks with AI-assisted explanation, while keeping finding generation deterministic.
- **Actual intended use in this project:** Synthetic-data portfolio demonstration of a read-only CRM export audit and explanation workflow.
- **Intended users and deployers:** Portfolio author/local demo operator is the only documented operator. No deploying company, customer, or organizational user group is established. A future CRM user is hypothetical.
- **Decisions, recommendations, or actions supported:** The tool flags selected CRM records for review and presents explanatory text. It does not make or automate a business decision, rank people, select applicants, or write to CRM. The reported missing-owner flags are review flags under a provisional rule, not confirmed errors.
- **Explicitly out of scope:** Real or sensitive customer CRM data; customer or production deployment; CRM write-back; reliance on model explanations as verified findings or as the sole basis for business action.
- **Where and under what conditions:** Local FastAPI service integrated with Open WebUI and a hosted model in a documented synthetic demonstration. Actual deployment entity, EU country, market offering, and professional-use context are unresolved.
- **Could use context or intended purpose change?** Yes. A new model/provider, real data, external users, production or customer deployment, HR/applicant ranking, employee evaluation, automated decisions, or another Annex III / Article 50 use would require reassessment.

- **Inputs, outputs, and interfaces:** Synthetic contacts/deals CSV files and optional association CSV; API produces structured findings and report content; Workspace Tool returns report content to chat context for model explanation.

Hosted-provider retention, access, transfers, exact processing terms, and data location are not established. - **People/groups affected and possible impacts:** No real individuals or customer organizations are represented in the intended synthetic scenario. In hypothetical use, CRM users, customers, sales staff, or employees could be indirectly affected if inaccurate flags or explanations influence reporting or action. No real-world impact study exists.
